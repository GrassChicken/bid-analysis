# 🏗️ 工程开标参数预测系统 V6.0

> 基于前后端分离架构的新一代工程招投标参数预测平台

## 🚀 项目简介

V6.0 是基于模块化架构重构的工程开标参数预测系统，采用前后端分离设计，具备更高的可维护性和扩展性。

### ✨ 核心特性

- 🔐 **用户系统** - 完整的认证授权体系
- 📊 **数据管理** - Excel 批量导入/导出/过滤
- 🤖 **智能预测** - 15+ 统计算法 + AI 分析
- 📱 **响应式设计** - 移动端友好
- 🔄 **PWA 支持** - 可安装应用
- 📈 **可视化分析** - 图表展示

### 🏗️ 模块化架构

```
v6/
├── app.py                 # 应用入口
├── start-v6.sh           # 启动脚本
├── requirements.txt       # 依赖包
├── .env.v6               # V6.0 环境配置
├── backend/              # 后端代码
│   ├── config/           # 配置管理
│   │   └── config.py     # 配置类
│   ├── models/           # 数据模型
│   │   ├── user.py       # 用户模型
│   │   ├── bid_record.py # 开标记录模型
│   │   └── prediction.py # 预测模型
│   ├── routes/           # 路由层
│   │   ├── auth.py       # 认证路由
│   │   ├── dashboard.py  # 仪表盘路由
│   │   ├── data.py       # 数据路由
│   │   ├── predict.py    # 预测路由
│   │   └── history.py    # 历史路由
│   ├── services/         # 业务服务
│   │   └── user_service.py # 用户服务
│   └── utils/            # 工具函数
│       └── database.py   # 数据库工具
├── frontend/             # 前端代码
├── static/               # 静态资源
└── templates/            # 模板文件
```

## 🚀 快速开始

### 环境要求

- Python 3.6+
- Flask 2.0+

### 安装部署

```bash

cd /root/.openclaw/workspace/v6

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
./start-v6.sh
```

## 🛠️ 开发指南

### 模块化开发

V6.0 采用模块化架构，各功能模块独立开发和维护：

1. **Models** - 数据访问层
2. **Routes** - 控制器层  
3. **Services** - 业务逻辑层
4. **Utils** - 工具函数层

### 代码规范

- 使用 Config 类管理配置
- 统一错误处理机制
- 模块间低耦合设计
- 前后端完全分离

## 📊 技术栈

- **后端**: Flask 2.0+, Python 3.6+
- **数据库**: SQLite
- **前端**: Vue3 + TailwindCSS
- **图表**: Chart.js
- **部署**: Gunicorn (生产环境)

## 🔐 安全特性

- 密码使用 werkzeug 安全哈希
- 会话管理安全
- SQL 注入防护
- 输入验证
