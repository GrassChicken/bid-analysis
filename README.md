# 🏗️ 工程开标参数预测系统 V6.0

> 基于前后端分离架构的新一代工程招投标参数预测平台

## 🚀 项目简介

V6.0 是基于模块化架构重构的工程开标参数预测系统，采用前后端分离设计，具备更高的可维护性和扩展性。

### ✨ 核心特性

- 🔐 **用户系统** - 完整的认证授权体系
- 📊 **数据管理** - Excel 批量导入/导出/过滤
- 🤖 **智能预测** - 15+ 统计算法 + AI 分析
- 📱 **响应式设计** - 移动端友好
- 🔄 **PWA 支持** - 可安装应用
- 📈 **可视化分析** - 图表展示

## 📐 V6.0 开发规划与优化路线图

> 以下规划按优先级分 4 个阶段推进

### 🔴 P0 - 高优先级（直接影响核心体验）

#### 1. 真实值自动匹配功能
**现状**：用户需要手动逐条录入真实值，效率低。

**方案**：
- 在"数据管理"页面导入的真实开标数据中，自动匹配项目名称+地点
- 自动回填到准确率分析的 `k1_actual` / `q1_actual` / `method_actual` 字段
- 支持一键批量回填未匹配的记录
- 匹配成功时显示"✅ 已自动匹配 XX 条记录"

**技术要点**：
- 在 `BidRecord` 模型中增加匹配逻辑
- 使用模糊匹配（项目名称相似度 ≥ 80%）
- 冲突处理：已录入真实值 → 跳过/提示

#### 2. 预测结果导出/下载
**现状**：预测结果只能在页面查看，无法导出。

**方案**：
- 预测结果页面增加"导出为 Excel"按钮
- 预测历史记录页面支持批量导出
- 导出内容：项目名称、预测时间、预测值、真实值、偏差、偏差等级

**技术要点**：
- 使用 `openpyxl` 或 `pandas` 生成 Excel
- 支持自定义导出字段

---

### 🟠 P1 - 中优先级（提升使用效率）

#### 3. 预测算法效能排名
**现状**：知道预测值，但不知道哪种算法最准。

**方案**：
- 准确率分析页面新增"算法效能"Tab
- 按算法分类统计命中率（众数法、中位数法、移动平均等）
- 显示 TOP 3 推荐算法 + 推荐理由
- 下次预测时自动推荐最优算法

#### 4. 月度/季度准确率趋势图
**现状**：只有偏差分布条，缺少时间趋势。

**方案**：
- 准确率分析页面新增折线图（按月份展示 K1/Q1 偏差变化）
- 对比不同月份准确率变化趋势
- 支持按项目名称、地点筛选

#### 5. 批量录入真实值
**现状**：只能逐条点击 ✏️ 按钮录入。

**方案**：
- 支持 Excel 模板导入真实值（项目名 + K1真实值 + Q1真实值 + 方法真实值）
- 导入预览 + 确认 + 冲突处理
- 导入结果统计（成功 XX 条，失败 XX 条）

---

### 🟡 P2 - 体验优化（锦上添花）

- 模板支持编辑、删除、排序

#### 7. 预测结果分享
**方案**：
- 生成预测结果分享链接（只读模式）

- 微信/钉钉分享卡片

#### 8. 数据管理增强
**方案**：
- Excel 导入时自动去重
- 支持按条件批量删除/批量修改
- 数据变更历史（谁在什么时候改了什么）

## 🛠️ 开发指南

### 模块化开发

V6.0 采用模块化架构，各功能模块独立开发和维护：

1. **Models** - 数据访问层
2. **Routes** - 控制器层  
3. **Services** - 业务逻辑层
4. **Utils** - 工具函数层

### 代码规范

- 使用 Config 类管理配置
- 统一错误处理机制
- 模块间低耦合设计
- 前后端完全分离

## 📊 技术栈

- **后端**: Flask 2.0+, Python 3.6+
- **数据库**: SQLite
- **前端**: Vue3 + TailwindCSS
- **图表**: Chart.js
- **部署**: Gunicorn (生产环境)
